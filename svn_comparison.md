1.	Почему в Git ветвление "дешёвое", а в SVN — "дорогое"?
В Гит ветка - это указатель на коммит (байты). В SVN ветка представляет собой копирование директории на сервере (тяжелее).
2.	Можно ли в SVN сделать коммит без интернета? Почему?
Нет, нельзя, потому что нужна связь с сервером, в гит для этого есть локальный репозиторий
