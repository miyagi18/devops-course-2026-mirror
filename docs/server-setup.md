# Конфигурация виртуальной машины devops-vm

## 1. Параметры машины
- **Оперативная память:** 2048 МБ
- **Количество ядер процессора:** 2
- **Объём дискового накопителя:** 25 ГБ (динамически расширяемый)

## 2. Сетевые интерфейсы
- **Адаптер 1 (NAT):** IP `10.0.2.15`. Обеспечивает доступ виртуальной машины в Интернет (для обновления пакетов).
- **Адаптер 2 (Host-only):** IP `192.168.56.101`. Обеспечивает изолированную связь между хостовой системой и виртуальной машиной.

## 3. Правило проброса портов
- **Порт хостовой системы:** 2222
- **Порт гостевой системы:** 2222 (изменён в ходе работы №5 для усиления безопасности)
- **Протокол:** TCP

## 4. Учётные записи
- **student:** основной пользователь, имеет права `sudo` через пароль.
- **devops:** специальный пользователь для администрирования, добавлен в группу `sudo`. Аутентификация только по SSH-ключу (`~/.ssh/devops_vm`).

## 5. Служба SSH
- **Порт:** 2222
- **Файл конфигурации:** `/etc/ssh/sshd_config.d/99-hardening.conf`
- **Изменённые директивы:**
  - `PermitRootLogin no`
  - `PasswordAuthentication no`
  - `PubkeyAuthentication yes`
  - `MaxAuthTries 3`
  - `AllowUsers devops`

## 6. Правила межсетевого экрана (UFW)
- **Политики по умолчанию:** `deny` (входящий), `allow` (исходящий).
- **Разрешающие правила:**
  - `2222/tcp` (LIMIT) — SSH с ограничением частоты подключений.
  - `80/tcp` (ALLOW) — HTTP (для будущей работы с Nginx).
  - `443/tcp` (ALLOW) — HTTPS (для будущей работы с Nginx).

## 7. Снимки состояния
1. `01-clean-install` — чистая установка Ubuntu Server.
2. `02-keys-configured` — настроена ключевая аутентификация.
3. `03-ssh-hardened` — усиlena защита SSH, изменён порт.
4. `04-ufw-configured` — настроен межсетевой экран UFW и локальное доменное имя.

## 8. Веб-сервер
- **Устанавливаемый пакет:** `nginx`
- **Путь к конфигурации ресурса:** `/etc/nginx/sites-available/devops-site` (активирован через симлинк в `/etc/nginx/sites-enabled/`)
- **Каталог ресурса:** `/var/www/devops-site`, владелец: `devops:devops`, права: `755` для каталога, `644` для файлов.
- **Открытый сертификат:** `/etc/ssl/certs/devops.crt` (права `644`, владелец `root:root`)
- **Закрытый ключ:** `/etc/ssl/private/devops.key` (права `600`, владелец `root:root`)
- **Команда формирования сертификата:** `sudo openssl req -x509 -nodes -days 365 -newkey rsa:2048 -keyout /etc/ssl/private/devops.key -out /etc/ssl/certs/devops.crt -subj "/CN=devops.local" -addext "subjectAltName=DNS:devops.local"`
- **Срок действия:** 365 дней.
